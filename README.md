# MULTIMODAL-AI-TOOLS-FOR-COMPARISION
Multimodal AI Tools Comparison for Students

Capstone Project – 57

Developed by: Reshma Anandhan

📌 Project Overview

Multimodal AI Tools Comparison for Students is a web-based application developed using Python and Flask. This project helps students explore, compare, and evaluate different AI tools and understand their capabilities through a user-friendly interface.

The application provides features for AI tool evaluation, prompt management, quizzes, tasks, reports, and presentations.

🎯 Objectives

- To explore and compare different AI tools.
- To help students understand multimodal AI technologies.
- To evaluate AI tools based on their capabilities.
- To provide an interactive platform for learning and assessment.
- To generate reports for evaluation purposes.

✨ Key Features

- AI Tools: Explore and manage AI tools.
- Tool Evaluation: Evaluate and compare AI tools.
- Prompt Management: Manage AI prompts.
- Quiz Module: Interactive quiz functionality.
- Task Management: Manage student tasks.
- Reports: Generate evaluation reports.
- Presentation: Access project presentation materials.
- Database Management: Store and manage application data.

⚙️ Installation and Setup

1. Clone the repository:

git clone https://github.com/reshhshades/MULTIMODAL-AI-TOOLS-FOR-COMPARISON.git

2. Navigate to the project folder:

cd MULTIMODAL-AI-TOOLS-FOR-COMPARISON

3. Create a virtual environment:

python -m venv venv

4. Activate the environment (Windows):

venv\Scripts\activate

5. Install dependencies:

pip install -r requirements.txt

6. Run the application:

python app.py

7. Open the application in your browser using the local URL displayed in the terminal.
